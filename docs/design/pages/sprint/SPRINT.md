# «Дебютный спринт» — `/sprint` (вместо «Угадай дебют»)

«Угадай дебют» учит угадывать название дебюта по первым ходам — играть от этого лучше не станешь.
Спринт тренирует то, что нужно в партии: **мгновенно вспомнить свой ход**. Позиции из твоих линий идут вперемешку на время. Быстро сыгранный дебют — это лишние минуты на миттельшпиль: «Где я теряю очки» как раз показывает время на ход в дебюте.

Макет: `docs/design/mockups/sprint.html` (`#end` — итог). Картинки: `target-run(-numbered).png`, `target-end(-numbered).png`.

## 1. Адрес и меню
- Новая страница `/sprint`. `/guess-opening` перенаправляет на `/sprint` (серверный `redirect()`).
- В `NAV_GROUPS` вместо «Угадай дебют» ставим «Дебютный спринт»: `href: '/sprint'`, `icon: 'sprint'`. В `NavIcon.tsx` добавить ключ `sprint` (иконка lucide `timer`):
  ```tsx
  sprint: <><line x1="10" x2="14" y1="2" y2="2"/><line x1="12" x2="15" y1="14" y2="11"/><circle cx="12" cy="14" r="8"/></>
  ```
- Пункт стоит там же, где был «Угадай дебют», — после «Расчёта вслепую» (как на макете).
- Ссылки на `/guess-opening` в «Сегодня» и в поиске заменить на `/sprint`.
- Старую страницу и таблицу `opening_guess_log` не удаляем, просто больше не ссылаемся на них.

## 2. Позиции
- `sprintItems` из `docs/design/pages/pages2-ref.cjs` — все твои ходы в линиях выбранных дебютов, начиная с 3-го полухода, без повторов (позиция + ход).
- Вес: линия к повторению ×3, трудный ход (`line_move_progress`, `incorrect_count > 0`) ×3, освоенная линия ×0.5.
- Порядок — `sprintOrder` (взвешенное перемешивание без повторов). Позиции кончились — перемешать заново.
- Цвет — `myColor` линии: у дебюта «за обе стороны» случайный, но один на всю сессию.

## 3. Забег
- **Время** — 1 / 3 / 5 мин (`localStorage`, ключ `sprint-time`, по умолчанию 3). **Жизней** — 3.
- **Позиция** появляется сразу, без проигрывания ходов до неё. Последний ход подсвечен, снизу твой цвет.
- **Верный ход** — +1 очко, серия +1, следующая позиция через 150 мс.
- **Неверный ход:**
  - жизнь −1, серия 0;
  - ошибка пишется в `line_move_progress`, как в тренажёре, — и попадает в «Трудные ходы»;
  - 900 мс на доске стрелки `played` и `best`;
  - в `sprint-log` строка «✗ **7... Qa5** · ты сыграл 7... O-O»;
  - потом следующая позиция;
  - таймер не останавливается.
- **Конец** — время вышло, жизни кончились или «Стоп» (`Esc`).

## 4. Раскладка (`TrainerLayout`)
**Слева:**
- «Дебютный спринт»;
- счёт: «рекорд» (лучший результат для выбранного времени) зелёным, «забегов», «точность» (верно / все ответы за всё время);
- «Время» (`sprint-time`);
- «Дебюты» (`sprint-openings`) — список с галочками и числом линий, выбор хранится в `localStorage` под ключом `sprint-openings`;
- «Последние забеги» (`session-list`) из `sprint_log`: «Вчера · 3 мин · 27 ★» (★ — рекорд).

**Справа, до старта:**
- заголовок «Дебютный спринт»;
- текст «Позиции из твоих линий, ход — твой. Ошибка — минус жизнь, три ошибки — конец забега.»;
- «Позиций: 58 из 4 дебютов»;
- кнопка `sprint-start` «Старт» (`Enter`).

**Во время забега:**
- шапка «Тренироваться · Дебютный спринт», справа «3 мин»;
- заголовок — таймер `sprint-timer` «1:42» (56px, цифры одной ширины);
- чипы: дебют позиции, «ход белых | чёрных», «твой ход из линии»;
- `sprint-score` — три ячейки:
  - «12» с подписью «очков» (склонение: очко / очка / очков);
  - «серия 5»;
  - `sprint-lives` — сердечки и текст «2 из 3»;
- `sprint-log` — последние 5 ответов: ✓ / ✗, ход с номером, справа дебют;
- кнопка «Стоп» (`sprint-stop`, `Esc`) и строка «Ошибка — минус жизнь · три ошибки — конец забега».

**Итог** (`sprint-result`):
- заголовок «Забег окончен»;
- три цифры: «23 очка», «3 ошибки», «27 рекорд»; если рекорд побит — «Новый рекорд!» зелёным;
- «До рекорда не хватило 4 очков. Ошибки попали в «Трудные ходы» тренажёра.»;
- список ошибок (`sprint-log`), каждая ведёт в `/openings/{id}?mode=hard`;
- кнопки: «Ещё раз» (`sprint-again`, `Enter`), «Трудные ходы», «К дебютам».

Запись в `sprint_log` в конце забега: `seconds`, `score`, `mistakes`, `positions` (SQL 34).

## 5. Демо `/sprint?demo=1` (без базы, `data-demo="sprint"` у панели)
- **Линии:** демо-тренажёр дебютов — L1–L6 «Ускоренного дракона» (чёрными), S1 и S2 «Шотландской» (белыми).
- **Первые 5 позиций — по порядку:**
  1. L2, после 4. Nxd4 → 4... g6;
  2. L5, после 3. Bb5 → 3... g6;
  3. L3, после 5. Nc3 → 5... Bg7;
  4. L6, после 2. c3 → 2... Nf6;
  5. S2, после 3... exd4 → 4. Nxd4.

  Дальше — `sprintOrder(items, rng(1))`.
- **Слева:** рекорд 27, забегов 14, точность 88%; история — как на макете.
- В базу ничего не пишется.
