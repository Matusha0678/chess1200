# «Ловушки» — `/traps`

Сейчас страница пустая, пока в курсах нет разделов «## Ловушка». Новая страница работает сразу:
- **17 проверенных ловушек** из библиотеки, подобранных к твоим дебютам;
- ловушки из курсов, как раньше;
- задачи из реальных партий Lichess в твоих дебютах — через «Тактику».

Макет: `docs/design/mockups/traps.html` (`#avoid` — «Не попадись»). Картинки: `target-punish(-numbered).png`, `target-avoid(-numbered).png`.

## 1. Откуда ловушки
1. **Библиотека** — `docs/design/pages/traps/traps-library.json`, перенести в `src/data/traps.ts`, 17 штук. Каждая проверена Stockfish (глубина 15–16):
   - все ходы легальны;
   - ошибка жертвы стоит не меньше 2 пешек или ведёт к мату;
   - каждый ход наказания держит перевес не меньше +1.5 или ставит мат;
   - ходы `safe` хуже лучшего не больше чем на 0.8.

   Ходы и тексты не меняй без проверки движком. Поля:
   - `line` — ходы до ошибки жертвы включительно;
   - `punish` — наказание, начиная с хода ставящего;
   - `setter` — кто ставит ловушку;
   - `safe` — верные ходы жертвы вместо ошибки;
   - `idea` — объяснение, `result` — итог.
2. **Курсы** (старый источник: `lesson_lines` с «ловушка» в названии):
   - `line` — все ходы, кроме последнего; `punish` — последний ход; `setter` — цвет последнего хода; `safe = []` (режима «Не попадись» нет);
   - **ключ — тот же, что был:** `${course.slug}/${lesson_order}/${line_order}`. Тогда сохранятся `trap_hits` и `trap_eval`. У ловушек из библиотеки ключ `lib:<id>`.
3. **Lichess.** Строка «Из партий Lichess» ведёт в «Тактику», режим «Мои дебюты» (раздел 6).

## 2. Какие ловушки «в твоих дебютах»
Функция `matchTrap` из `docs/design/pages/pages2-ref.cjs`. Идём по ходам ловушки, пока позиции есть в линиях дебюта (сравнение по позиции). Ловушка подходит, если:
- первым из твоих линий ушёл **соперник** (тебе не надо менять репертуар), и общее начало — не меньше 2 полуходов;
- или если твои линии доходят до самой ошибки.

Роль считается от твоего цвета в этом дебюте:
- `setter` — «Ты ставишь» (зелёная иконка `swords`);
- `victim` — «Тебе ставят» (оранжевая `shield`).

Пример: к «Итальянской» подходят «Блэкберн» (3...Nd4 — ход соперника) и «Мат Легаля» (2...d6). «Ноев ковчег» не подходит: 3.Bb5 — твой ход.
Порядок — `trapsForRepertoire`: по порядку дебютов, внутри — сначала с более длинным общим началом.

## 3. Раскладка (`TrainerLayout`)
**Слева** (`SessionPanel`):
- «Ловушки» и их число;
- счёт: «выучено» (уровень ≥ 4) зелёным, «повторить» оранжевым, «новых»;
- фильтр `trap-filter`: «Все / Я ставлю / Мне ставят»;
- кнопка `trap-session` «Тренировать · N» (`Enter`);
- список (`session-list`) с группами:
  - «В твоих дебютах»;
  - «Из курсов»;
  - строка `trap-lichess` «Из партий Lichess · N задач по твоим дебютам · в «Тактике»»;
  - «Другие ловушки».

  Строка ловушки (`trap-row`, у неё `data-trap=<id или ключ>`, `data-role`, `data-status`, у активной `data-active="true"`):
  - иконка роли;
  - название;
  - ниже «{дебют} · ставишь | ставят · новая | повторить | выучена»;
  - справа точка статуса: синяя — новая, оранжевая — повторить, ✓ — выучена.

**Доска:**
- снизу тот, кто тренируется. В «Накажи» — ставящий, в «Не попадись» — жертва;
- `lastMove` — последний сыгранный ход;
- полоска сверху: «после **6. Bg5??** · ход чёрных»;
- значков нет.

**Справа:**
- шапка «Учиться · Ловушки», справа «1 / 8», если идёт сессия;
- заголовок — название ловушки, после ошибки — «Попался!»;
- чипы: роль, дебют (с королём цвета), «Итог: мат | ферзь | фигура | ладья | выигрыш»;
- блоки:
  - `trap-story` — объяснение (`idea`); в «Накажи» — без ответа;
  - `trap-task` (`data-result="info"`) — что делать сейчас;
  - `trap-feedback` (`data-result="ok|fail"`) — итог хода;
  - `trap-line` — ходы ловушки с номерами: ошибка красная с «??», ходы наказания зелёные (в «Накажи» — только уже найденные, на месте следующего «?»), справа «твой ход 1 из 3»;
  - `trap-hits` — «Поймал соперника · N», «Попался сам · N»: запись в `trap_hits`, как раньше;
- кнопки: `trap-watch` «▶ Смотреть», `trap-punish` «Накажи сам», `trap-avoid` «Не попадись» (если у ловушки есть `safe`); после итога — `trap-next` «Дальше» (`Enter`) и `trap-retry` «Ещё раз».

## 4. Режимы
**▶ Смотреть.** Вся линия и наказание по 900 мс на полуход. На ошибке пауза 1,5 с: ошибка подсвечена в `trap-line`, в карточке — «Ошибка: 6. Bg5??». `Пробел` — пауза.

**Накажи сам** — по умолчанию для роли «ставишь» и для «Других»:
- прогон `punishRun` (режим `drill` из `opening-trainer.ts`, со старта после ошибки). Доска — позиция после ошибки жертвы, ходит ставящий;
- ответы жертвы — сами через 600 мс;
- **другой ход** сначала проверь движком (`useStockfish`, глубина 12). Если он тоже даёт ≥ +2.0 или мат — засчитай: карточка `ok` «Тоже выигрывает! В ловушке задумано **6... Nxe4**», доска продолжает по линии ловушки. Иначе — стрелки `played` и `best`, и ход надо сделать;
- `H` — подсказка, как в тренажёре дебютов;
- в конце карточка `ok`: «Верно! Мат.» (или «…выигрываешь ферзя» — по `result`), если без ошибок. С ошибками — `fail` «Ловушка сработала, но с ошибкой на 7... Bxf2+».

**Не попадись** — по умолчанию для роли «ставят»:
- позиция перед ошибкой, ходит жертва (ты). Проверка — `avoidVerdict`;
- `trap` — **попался**:
  - стрелки `played` (красная) и `best` (зелёная пунктирная, первый из `safe`);
  - заголовок «Попался!»;
  - карточка `fail`: «**5. Nxf7??** — это и есть ловушка: **5... Qxg2 6. Rf1 Qxe4+ 7. Be2 Nf3#**», ниже «Здесь надо **5. O-O** или **5. Bxf7+**.»;
  - кнопка «▶ Показать мат»;
- `safe` — `ok`: «Верно: **5. O-O** — ловушки нет.»;
- `other` — движок (глубина 12):
  - хуже лучшего не больше чем на 0.8 — `ok` «Можно и так. Чаще играют **5. O-O**.»;
  - иначе — `fail` и две стрелки.

**Тренировать** (сессия):
- очередь: ловушки с подошедшим сроком (любые), потом новые из «твоих дебютов» (не больше 8);
- режим — «Накажи» для «ставишь» и «Других», «Не попадись» для «ставят»;
- итог сессии: «8 ловушек · 6 верно · следующее повторение — завтра».

**Прогресс** — таблица `trap_progress` (SQL 34). Те же правила, что у линий: `applyResult` и `lineStatus` из `opening-trainer.ts`; «выучена» — уровень ≥ 4.

## 5. Пусто и ошибки
- Ловушки есть всегда — из библиотеки.
- Дебютов нет — группа «В твоих дебютах» пустая, подпись «Добавь дебюты — подберём ловушки к ним».
- Ошибки базы — «Ошибка базы: …».

## 6. «Тактика» → режим «Мои дебюты» (`/tactics?mode=openings`)
- **Ключ дебюта на Lichess** — по позиции, а не по названию:
  - `src/data/eco.json` собирает скрипт `scripts/build-eco.mjs` из таблиц `a.tsv`–`e.tsv` репозитория `lichess-org/chess-openings` (лицензия CC0) — по строке на позицию: `[eco, name, posKey, plies]`;
  - `openingOf(line)` — самая глубокая названная позиция на линии;
  - ключ — `nameToKey`, как в scalachess: убрать диакритику, пробелы заменить на `_`, удалить всё, кроме `[A-Za-z0-9_-]`;
  - для варианта берётся «Семейство: вариант» до первой запятой (`Sicilian Defense: Accelerated Dragon` → `Sicilian_Defense_Accelerated_Dragon`), для семейства — только «Семейство» (`Sicilian_Defense`).
- **Загрузка** — кнопка «Загрузить задачи из моих дебютов». На каждый дебют один запрос `/api/lichess/puzzles?angle=<ключ варианта>&nb=50`, строго по одному. Если задач нет или ответ 4xx — тот же запрос с ключом семейства.
- **Сохранение** — `upsert` в `puzzles` с `opening_key` (SQL 34). В `src/app/api/lichess/puzzles/route.ts` поправить проверку: `SAFE_ANGLE = /^[A-Za-z0-9_-]+$/`, иначе ключи с `_` и `-` не пройдут.
- **Режим** — новый пункт «Мои дебюты» в левом списке «Тактики», после «Мои слабые темы». Задачи, где `opening_key` — ключ одного из твоих дебютов. Сначала задачи с темой `opening` (тактика в дебюте), потом остальные. Решаются как обычные задачи «Тактики».
- **Число на странице «Ловушки»** («24 задачи») — столько таких задач уже в базе. Если 0 — «Загрузить в «Тактике»».
