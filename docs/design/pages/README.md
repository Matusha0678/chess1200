# Переделка «Проверки угроз» и «Жертв»

## Сначала — логика

Пользователь недоволен не только видом: «жертвы» сейчас — ходы пешкой и простые взятия, «угрозы» — бессмыслица. Поэтому **первым делом** — `LOGIC.md`: что считать жертвой и угрозой, данные, тесты. Если вид уже переделан — логика всё равно нужна целиком.

Второе — **объяснения на доске** (`BOARD-EXPLAIN.md`): стрелки плана с номерами, значки, подсветка хода, свечение шаха, рамки на отмеченных клетках, показ варианта при наведении. Пользователю это нравится больше всего, а сейчас после ответа доска пустая.

## Почему это задание

В прошлый раз эти две страницы только обернули в `TrainerLayout`. Содержимое осталось старым: нет левой колонки, нет полосок игроков, старая шапка, вкладки, карточки статистики, кнопки не там, справа пустое место. Сейчас нужно **переделать содержимое этих страниц полностью** по макетам. Страница «Ошибки» сделана хорошо — она образец.

## Метки `data-ui` (нужны для автопроверки)

Поставь атрибут `data-ui` на эти элементы на всех трёх страницах («Ошибки», «Угрозы», «Жертвы»):

| `data-ui` | Элемент |
|---|---|

## Что убрать со страниц навсегда

- Ссылки «← Сегодня», «← Мастера» в шапке панели (вместо них — крошки «Тренировка · …»).
- Вкладки «Тренажёр / Подготовить».
- Карточки статистики в правой панели («100% Верных», «Серия» и т. п.) — счёт живёт в левой колонке.
- «Позиция 1/31», «XP заработано» под доской и строки вида «Позиция 399 из 500 · …» внизу панели — это шапка панели.
- Белые главные кнопки. Главная кнопка всегда зелёная, внизу панели.
- Кнопка «Блиц» как отдельная кнопка — это переключатель в левой колонке.
