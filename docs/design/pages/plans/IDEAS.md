# «Идеи позиций» — `/plans`

Сейчас страница пустая: карточки берутся только из блоков `idea` в курсах.
Новая страница отвечает на вопрос, который мешает на 1000–1600: **«моя линия кончилась — что играть дальше?»** Для каждой позиции, где кончаются твои линии, она показывает:
- какие ходы делают мастера (база мастеров Lichess) и с каким результатом;
- план движка;
- партии мастеров с этой позиции.

Режим «Проверь себя» — сыграй ход «как мастер».
Карточки из курсов остаются отдельной группой.

Макет: `docs/design/mockups/plans.html` (`#quiz` — «Проверь себя»). Картинки: `target-explore(-numbered).png`, `target-quiz(-numbered).png`.

## 1. Позиции
- `endPositions` из `docs/design/pages/pages2-ref.cjs` — последние позиции всех линий, без повторов по позиции.
- Если в конце линии ход соперника — берём его **самый частый ответ** (мастера → Lichess 1600–2000 → лучший ход движка). Показываем позицию после этого ответа, где ходишь ты. В подписи «Твоя линия кончается на **10... Be6**. Чаще всего белые отвечают **11. O-O** — 55% партий».
- Если в конце линии ход твой — сразу эта позиция.
- Строка в списке (`idea-row`, `data-pos`, `data-status`):
  - «После 10... Be6»;
  - ниже — подпись линии (`lineLabels` из `opening-trainer.ts`) и «131 партия»;
  - справа точка статуса.

## 2. Данные
- **`/api/lichess/explorer` — добавить `db=masters`.** Запрос `https://explorer.lichess.org/masters?fen=…&moves=8&topGames=4` с `LICHESS_TOKEN`. Ответ `{ total, moves: [{ uci, san, white, draws, black }], topGames: [{ id, white: {name, rating}, black: {name, rating}, year, winner }] }`. Без `db` ответ остаётся прежним — им пользуется «Дебюты в партиях».
- **Новый маршрут `/api/lichess/masters-pgn?id=`** → `https://explorer.lichess.org/masters/pgn/{id}` (токен, текст PGN).
- **Кеш** — таблица `position_explorer` (`pos_key`, `db`, `data`, `fetched_at`; SQL 34):
  - сначала читаем кеш; запрашиваем, только если записи нет или ей больше 30 дней;
  - запросы — строго по одному;
  - на `429` — «Lichess просит подождать минуту» и повтор через 60 с.
- **Нет токена** (`503 no_token`) — режим «Stockfish»:
  - три лучших хода (`multipv 3`, глубина 14, в воркере), в таблице оценка вместо процентов;
  - чип «Stockfish» вместо «Мастера»;
  - сверху блок `idea-token`: «Добавь LICHESS_TOKEN — покажем ходы мастеров» и как это сделать (`.env.local` и Vercel).

## 3. Раскладка (`TrainerLayout`)
**Слева:**
- «Идеи позиций» и «N позиций»;
- счёт «изучено / повторить / новых» — по `idea_progress`, ключ `pos:<posKey>`, правила те же, что у линий дебютов: `applyResult`, «изучено» — уровень ≥ 4;
- режимы `idea-modes`: «Изучать | Проверь себя»;
- подпись «Где кончаются твои линии»;
- список по дебютам: заголовок группы — король цвета, название, число;
- группа «Из курсов» — старые карточки `idea` с прежними ключами и прогрессом, решаются как раньше (вопрос с вариантами).

**Доска:** позиция, где ходишь ты; твой цвет снизу.
- «Изучать» — стрелки трёх самых частых ходов (`role: 'plan'`, номера 1 / 2 / 3; 2-я и 3-я бледнее).
- «Проверь себя» — до ответа стрелок нет.

**Справа:**
- шапка «Учиться · Идеи позиций», справа «2 / 12»;
- заголовок «Что играть после 11. O-O»;
- чипы: дебют, «ход белых | чёрных», «Мастера · 131 партия» или «Stockfish»; в демо — «демо»;
- `idea-context` — текст из раздела 1;
- `idea-moves` — до 4 ходов:
  - номер в кружке (синий у первых трёх);
  - ход с номером «11... Qa5»;
  - «40% · 52 партии»;
  - полоса результата «белые / ничья / чёрные» (`moveStats`);
- `idea-plan` — «План движка»: 6 полуходов главного варианта из позиции (глубина 18, воркер). Только ходы, без придуманных слов про план;
- `idea-games` — до 3 партий мастеров: «{Белые} ({рейтинг}) — {Чёрные} ({рейтинг}) · {год} · 1–0» и кнопка ▶;
- кнопки: `idea-quiz` «Проверь себя», `idea-watch` «▶ Партия», `idea-next` «Дальше N».

**▶ Партия:**
- загрузить PGN, найти в партии эту позицию (по `posKey`);
- проиграть 16 полуходов по 900 мс;
- строка `idea-step` «Ход 3 из 16», `←` / `→` — по ходу, `Esc` — назад к позиции;
- стрелка следующего хода — `plan`.

## 4. «Проверь себя»
- очередь: позиции с подошедшим сроком, потом новые (не больше 10);
- заголовок «Сыграй, как мастер»;
- пользователь ходит, оценка — `ideaVerdict`:
  - **верно** (ход из первых трёх или ≥ 10% партий) — карточка `idea-feedback` `ok`: «Так играют **40%** мастеров (52 партии)», справа появляется таблица `idea-moves`; уровень +1;
  - **не так** — ход не ставится, стрелки `played` и `best` (самый частый ход), карточка `fail`: «**11... h6** мастера почти не играли. Чаще всего здесь **11... Qa5** (40%), **11... a5** (29%), **11... Rc8** (17%).» Уровень тот же, срок ближе. Можно сыграть один из этих ходов — тогда `ok` без повышения уровня;
- `H` — подсказка: стрелка самого частого хода, засчитывается как «не так»;
- `N` — следующая позиция.

Запись: `idea_progress` (`upsert` по `idea_key`: `mastery`, `next_review`, `reviewed_at`).

## 5. Демо `/plans?demo=1` (без базы и сети, `data-demo="plans"` у панели)
- **Позиции** — концы линий демо-тренажёра дебютов: L1–L6 «Ускоренного дракона» (чёрными) и S1, S2 «Шотландской» (белыми), всего 8.
- **Открыта L2** «После 10... Be6» (у неё срок вчера):
  - ответ белых **11. O-O** (55%; в демо-статистике белых O-O 90, f3 35, Rc1 31, Bd4 9);
  - позиция после 11. O-O;
  - ходы чёрных: **Qa5** 52 партии (31/46/23), **a5** 38 (34/42/24), **Rc8** 22 (36/41/23), **a6** 14 (43/36/21), **Nd7** 5 (40/40/20) — числа для показа, чип «демо»;
  - план движка — готовый текст `11... a5 12. f4 a4 13. Bd4 Qa5 14. Rad1 Rfc8` (посчитан Stockfish на глубине 16);
  - партии — 3 строки «Игрок A (2654) — Игрок B (2701) · 2019 · 0–1» и т. д.; ▶ проигрывает этот вариант движка.
- **Прогресс:** L1 и S1 изучены, L2 и L3 повторить, остальные новые.
