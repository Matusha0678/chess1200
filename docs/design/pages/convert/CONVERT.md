# «Дожми свою партию» — `/convert`

Позиции из партий пользователя, где он был сильно впереди и не выиграл. Он доигрывает их против Stockfish, пока не выиграет. Макета нет — каталог как `/endgames` (те же размеры, карточки, левая колонка). Ветка `feat/convert`. Пункт меню «Дожми партию» в группе «Тренироваться» после «Эндшпили», иконка `target`.

## 1. Данные
- Позиции: `game_insights.convert_fen`, `convert_move_number`, `convert_eval`, `convert_my_win` (таблица и подсчёт — `STATS.md`, `ensureInsights()`), плюс `games` (соперник, дата, итог, цвет).
- Результаты: `game_log` (уже есть). Партия с `/play`, начатая с этой позиции, пишется туда с `fen` = позиция. «Дожато» — есть строка с этим `fen` и `result = 'win'`; попытки — число строк с этим `fen`.

## 2. Раскладка (как `/endgames`)
**Метки** — те же, что в каталоге «Эндшпилей» (`eg-left`, `eg-grid`, `eg-card`, `eg-board`, `eg-card-title`, `eg-next`): так работают готовые проверки каталога.

**Слева** (`data-ui="eg-left"`, 280px):
- «Дожми партию» 19/700, справа «{N} из {M} дожато»; полоса 6px;
- счёт: «дожато» (зелёный), «в работе» (оранжевый), «новых»;
- «Сила Stockfish»: «Клубный · 10 / Сильный · 14 / Мастер · 18», по умолчанию 14, в `localStorage` (`cv-level`);
- «Показать»: Все / Новые / Дожатые;
- внизу (`data-ui="eg-next"`): «Следующая позиция» — миниатюра 84px, «vs {соперник} · {дата}», «Играть» (`Enter`).

**Основная колонка:** заголовок «Позиции из твоих партий» 30/700, подпись «{N позиций} · ты был впереди и не выиграл · играешь против Stockfish», справа «Случайная» (`R`). Сетка (`data-ui="eg-grid"`) `repeat(auto-fill, minmax(240px, 1fr))`, `gridAutoRows: 'max-content'` (урок `FIX-GRID.md`), прокручивается только сетка.

**Карточка** (`data-ui="eg-card"`, `data-status="solved|tried|new"`): `MiniBoard` в `data-ui="eg-board"` (квадратная, мой цвет снизу), в левом верхнем углу плашка «+3.8» (оценка за меня); под доской «vs {соперник} · {дата}» 15/600 (`data-ui="eg-card-title"`) и строка 13px «{N}-й ход · было: {ничья | поражение}», справа статус: «Дожато ✓» зелёным / «{N} попытки» оранжевым / «Новая». Наведение — как в «Эндшпилях»: затемнение, «Ты был +3.8 — дожми», круглая кнопка ▶. Сортировка: новые и начатые — по оценке ↓, дожатые — в конце.

**Клик** → `/play?fen={fen}&color={w|b}&level={уровень}&mode=free&from=convert`. На `/play` при `from=convert` — ссылка «← К позициям» в шапке панели; партия пишется в `game_log` как обычно.

**Пусто:** нет позиций — «Таких партий нет — ты дожимаешь всё»; инсайты ещё не посчитаны — считаем здесь же (`ensureInsights()`, прогресс слева).

## 3. Демо `/convert?demo=1`
`DEMO_CONVERT`: 8 позиций (настоящие FEN, проверь chess.js), 2 дожато, 2 начато, 4 новых. В базу не пишет; `data-demo="convert"` у основной колонки.

## 4. Проверка
`/convert` — в `LIST_PAGES` в `check-design.mjs`, как `/endgames`: `ui: ['eg-left','eg-next','eg-grid','eg-card','eg-board','eg-card-title']`, `minCols: { 1920: 5, 1440: 3 }`, `minBoard: 230`, `forbidden: []`, `titleNotIn: []`; `node docs/design/check-design.mjs http://localhost:3001 /convert --no-answers` — 0 ошибок; скриншоты: каталог и наведение; руками — клик открывает `/play` с этой позицией и нужным цветом.
