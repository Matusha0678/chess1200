# «Расчёт вслепую» — `/blind`

Тренировка счёта в уме: доска **не двигается**, первые ходы решения показаны только текстом, а следующий ход надо найти в уме. Макета нет — раскладка как у `/threats` (`TrainerLayout`). Ветка `feat/blind`. Пункт меню «Расчёт вслепую» в группе «Тренироваться» после «Тактика», иконка `eye`.

## 1. Откуда задачи
Таблица `puzzles` из «Тактики» (`TACTICS.md`). Для уровня L нужны задачи, где в решении не меньше `2L + 1` ходов. Мало таких задач (меньше 10 нерешённых) — кнопка «Загрузить 50 задач» (`angle=long` для L ≥ 2, иначе `mix`). Попытки — в `puzzle_attempts` (`set_id = null`, `cycle = null`), в поле `seconds` — время ответа.

## 2. Как устроено
1. Доска: `fen_start` → анимация `last_move` → позиция задачи. Дальше доска **стоит**.
2. Уровень L (1 / 2 / 3 хода в уме, слева, в `localStorage` `blind-level`): в панели строка ходов (`data-ui="blind-line"`) — первые `2L` полуходов решения в SAN с номерами, крупными чипами 17/600 (например, L = 1 в задаче `0haqU`: «27... d3+ 28. Nxc5»).
3. Задание: «Представь эти ходы и найди следующий ход {белых|чёрных}. Доска не двигается: нажми клетку «откуда», потом «куда».»
4. Ввод: два клика по клеткам (`onSquareClick`, без проверки по позиции на доске — фигуры там уже нет или стоит другая). Выбранные клетки — кольца `#4A90E2`. Превращение — в ферзя. Отмена выбора — клик по той же клетке или `Esc`.
5. Проверка: на скрытой доске сыграть первые `2L` ходов; ответ верный, если `from + to` = `solution[2L]` (без буквы превращения) или ход ставит мат.
6. После ответа доска оживает: показанные ходы проигрываются по 900 мс, потом ход:
   - верно — ответ сыгран, значок `best` на нём, зелёная карточка «Верно, ты увидел позицию» и время;
   - неверно — позиция перед ответом; красная стрелка твоего хода (если он возможен в этой позиции; `role: 'played'`) и зелёная пунктирная верного (`role: 'best'`); значков нет; карточка «Не то. Здесь {SAN}».
7. Карточка результата — `data-ui="blind-feedback"`, `data-result="ok|fail"`.

**Слева** (`SessionPanel` «Вслепую»): счёт «верно / ошибок / серия»; уровень; подпись «Задачи из «Тактики»: {N} подходят». Нет задач — «Сначала загрузи задачи в «Тактике»» и кнопка.
**Панель:** шапка «Тренировка · Расчёт вслепую», заголовок «Представь ходы», чипы «{L} хода в уме», «Рейтинг {rating}»; строка ходов; задание; карточка результата; низ: «Подсказка» (`H` — кольцо на клетке «откуда» верного хода, попытка не засчитывается как верная), «Показать ходы» (проиграть и ответ — попытка неверная), «Дальше» (`Пробел` / `Enter`).

## 3. Демо `/blind?demo=1`
Задача `0haqU` из `TACTICS.md` (решают чёрные; решение d3+ Nxc5 dxc2 Nxb7 c1=Q+): L = 1 — показать «27... d3+ 28. Nxc5», ответ `d3c2` (28... dxc2); L = 2 — показать «27... d3+ 28. Nxc5 dxc2 29. Nxb7», ответ `c2c1` (29... c1=Q+). Без базы; `data-demo="blind"` у панели.

## 4. Проверка
`/blind` в `STRUCTURE`, `PAGE_UI`: `'blind-line'`, `'blind-feedback|blind-task'`. Демо-проход в `ANSWER_FLOWS`: `/blind?demo=1` → клики по `d3` и `c2` → `data-result="ok"`; новая задача → клики по двум неверным клеткам → `data-result="fail"` и стрелка `best`. `npx tsc --noEmit`, `npx eslint src`, `npm run test:logic`, скриншоты: задание, верно, неверно.
