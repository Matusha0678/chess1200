## 2. Как надо: до проверки (`target-question-numbered.png`)

Сетка — `TrainerLayout` + `useTrainerGeometry` (DESIGN-SPEC, раздел 4). На 1920×950: левая 280, доска 768, правая 520.

**№1. Колонка «Сессия»** (`SessionPanel`, `data-ui="session"`). Шапка: «Сессия» 19/700, справа «осталось {N}» 14px `--muted`, N = позиций до конца.

**№2. Счёт** (`data-ui="session-stats"`): 3 ячейки — «нашёл» (зелёный `--accent`), «пропустил» (оранжевый `--c-warn`), «лишних» (красный `--c-bad`). Числа = сумма по сессии (`score.found`, `score.missed`, `score.falseAlarms`). Число 20/700, подпись 13px.

**№3. Переключатель режима** (`Segmented`): «Обычный» (иконка `mouse-pointer-click`) / «Блиц 60 с» (иконка `zap`). Заменяет старую кнопку «Блиц». В блице на каждую позицию 60 секунд: время показывается часами в нижней полоске игрока справа (светлая плашка, как активные часы, 18/600), при 0 — автоматически «Проверить». Переключать можно только между позициями (во время позиции — неактивно).

**№4. Список позиций** (`data-ui="session-list"`). Подпись «Позиции» и справа «4 / 31». Строки 50px:
- пройденная: слева ✓ (всё нашёл и без лишних), «!» оранжевый (нашёл не всё), ✗ красный (ничего не нашёл или ошибся с «Угроз нет»); название — тип угрозы этой позиции («Вилка конём», «Зевок ладьи», «Шах», «Угроза мата», «Выигрыш материала», «Угроз нет»); подпись — результат («нашёл 2 из 2», «нашёл 0 из 1», «верно», «ошибка»);
- текущая: номер зелёный 700, фон `--row`, полоска 3px слева; «Позиция 4», подпись «партия против {opp}»;
- следующие: номер `--faint`, «Позиция N», «партия против {opp}». **Тип угрозы до ответа не показывать.**
Список прокручивается внутри колонки; текущая строка всегда видна (scrollIntoView).

**№5. Низ колонки**: кнопка «Начать заново» (иконка `rotate-ccw`, 44px) — сброс счёта и новая подборка позиций.

**№6. Полоска соперника** (`PlayerBar`, `data-ui="player-top"`): квадрат 28px с пешкой цвета соперника, имя (`games.opp_name`, иначе «Соперник»), подпись «белые»/«чёрные»; справа «последний ход» 13px `--muted` + чип хода (SAN).

**№7. Доска** (`Board`): мой цвет снизу. `interactive={false}`, `onSquareClick` — отметки:
- клик по **своей** фигуре — отметить (синяя рамка 4px `#4A90E2` + заливка `rgba(74,144,226,.28)`), ещё клик — снять;
- клик по чужой фигуре или пустой клетке — ничего;
- последний ход соперника подсвечен: «откуда» `rgba(247,214,74,.42)`, «куда» `rgba(247,214,74,.55)`;
- если мне шах — свечение под королём.
Последний ход и имя соперника: найди партию позиции (`games` по `game_id`), проиграй `games.pgn` через chess.js до этой позиции (сравнивай первые 4 поля FEN) — предыдущий ход и есть последний ход соперника. Если партию найти нельзя — подсветки нет, в полоске «Соперник».

**№8. Полоска «ты»** (`data-ui="player-bottom"`): «{username}» (из `games_sync_state.username`), подпись «ты · чёрные/белые», справа «твой ход» 13px `--muted` (в блице — часы).

**№9. Шапка панели** (`TaskPanel`, `data-ui="panel-header"`): слева «Тренировка · Проверка угроз» 13px `--muted`; справа «4 / 31» (15/600) и чип «+45 XP» (XP за сессию); полоса прогресса 4px = текущая / всего; заголовок «Что хочет соперник?» 30px Inter Tight (`data-ui="panel-title"`); чипы: «Ты играешь чёрными», «Партия против {opp}».

**№10. Секция «Задание»** (`data-ui="threat-task"`): подпись «Задание»; текст 15px: «Соперник сыграл {чип хода}. Отметь свои фигуры, которые он может выиграть следующим ходом. Если угроз нет — нажми «Угроз нет».» Если последний ход неизвестен: «Отметь свои фигуры, которые соперник может выиграть следующим ходом…».

**№11. Секция «Что считается угрозой»** (`data-ui="threat-rules"`): 3 строки по 30px, иконка 18px `--muted` + текст 15px:
- `crown` — «Шах твоему королю»
- `triangle-alert` — «Фигура без защиты или под ударом более дешёвой»
- `git-fork` — «Вилка и двойной удар»

**№12. Секция «Отмечено: N»** (`data-ui="threat-marked"`): чипы (28px) — картинка фигуры 18px (из текущего набора фигур темы) + «c7 · пешка» + «✕» (клик снимает отметку и рамку на доске). Если ничего: «Пока ничего не отмечено» 14px `--muted`.

**№13. Низ панели** (`data-ui="panel-actions"`):
- главная зелёная «Проверить» + `Kbd` «Enter». Если ничего не отмечено — работает как «Угроз нет»;
- две второстепенные: «Угроз нет» (`N`), «Подсказка» (иконка `lightbulb`, `H`) — на 1.5 с оранжевая рамка на фигуре соперника, которая угрожает; −5 XP; один раз на позицию;
- строка 13px `--faint`: «Клик по фигуре — отметить · ещё клик — снять».

## 3. Как надо: после проверки (`target-answer-numbered.png`)

**№1. Доска** — строго по `BOARD-EXPLAIN.md`, раздел 3 (картинка `explain/threats-answer-numbered.png`):
- красная сплошная стрелка: ход-угроза соперника (`threat_uci`);
- оранжевые пунктирные стрелки: от клетки, куда пришла фигура, к моим целям вилки (и к королю, если шах);
- на клетках итог (рамка 4px + заливка + значок `ClassIcon` в правом верхнем углу):
  - нашёл — `found`, рамка `#81B64C`, заливка `rgba(129,182,76,.25)`;
  - пропустил — `missed`, `#F0A43A`, `rgba(240,164,58,.25)`;
  - лишняя — `wrong`, `#E0574A`, `rgba(224,87,74,.22)`;
- подсветка последнего хода остаётся; синие рамки отметок убираются (вместо них — итоговые);
- наведение на «Дальше: …» — вариант стрелками с номерами (`BOARD-EXPLAIN.md` 1.3).

**№2. Чипы результата** (вместо чипов вопроса): «Нашёл X из Y» (зелёный если X = Y, иначе оранжевый), «N лишняя отметка / лишние отметки» (красный; только если N > 0), «+XP» (зелёный).

**№3. Карточка угрозы** (`data-ui="threat-card"` + `data-result="threat"` или `"none"`), красная (`FeedbackCard` danger): значок — красный круг с `triangle-alert`; заголовок «Угроза: {SAN}» 19/700 `#F08277`; текст — по шаблону (раздел 5); строка «Дальше:» (`data-ui="threat-line"`) + 3 полухода `threat_pv` чипами + итог («— ты теряешь ладью», «— мат в 2 хода», «— соперник выигрывает 3.5 пешки»).
Если угроз не было: зелёная карточка «Угроз нет — верно!» (ничего не отмечено) или оранжевая «Угроз не было» (были отметки) + текст «Ход соперника ничего не выигрывает. Проверь отмеченные фигуры ниже.»

**№4. «Твои отметки»** (`data-ui="threat-marks"`): строка на каждую клетку из (отмеченные ∪ под угрозой): кружок 24px (зелёный ✓ / оранжевый «!» / красный ✕); «c7 · пешка» 15/600 + слово 13px цветом («нашёл», «пропустил», «лишняя»); причина 14px `--muted` одной фразой (раздел 5).

**№5. Шаг 2 «Найди защиту»** (`data-ui="threat-defense"`): плашка (фон `--surface-2`, рамка `--hairline-2`, радиус 12): иконка `shield-check` в зелёном квадрате 36px; «Шаг 2. Найди защиту» 15/700; «Сделай ход на доске, который убирает угрозу.» 14px `--muted`. Доска становится интерактивной для моих фигур (`interactive`, `movableColor` = мой цвет). После хода:
- угроза пропала (повтори поиск угрозы для новой позиции, см. раздел 4) **и** оценка упала не больше чем на 0.5 пешки → в плашке зелёным «Защита найдена: {SAN}», +5 XP;
- иначе → красным «Угроза осталась: {коротко почему}» и кнопка «Ещё раз» (вернуть позицию). Одна повторная попытка.

**№6. Низ панели:** главная «Дальше» (`Пробел`); второстепенные «Подсказка защиты» (`H`: зелёная пунктирная стрелка лучшего защитного хода) и «Сыграть отсюда» (иконка `circle-play`, PlayFromPosition с этой позиции, я — своим цветом); строка «Защиту можно пропустить — сразу «Дальше»».

**№7. Счёт в левой колонке** обновился сразу после «Проверить».

**№8. Строка позиции в списке** стала пройденной: статус, тип угрозы, результат.

## 4. Логика

**Позиции, поиск угрозы, цели, тип угрозы** — `LOGIC.md`, раздел 2 (заменяет прежний текст этого раздела; тип «Шах» убран). Демо-позиция `?demo=fork` — `BOARD-EXPLAIN.md`, раздел 4.

**Счёт и XP:** +15 за найденную, −5 за пропущенную и за лишнюю, за позицию не меньше 0. Защита +5. Подсказка −5. Запись в `threat_log` — как сейчас (found, missed, false_alarms, time_taken_ms).

**Блиц:** 60 с на позицию, таймер в нижней полоске; при 0 — «Проверить» с тем, что отмечено.

## 5. Тексты (шаблоны)

Названия фигур: пешка, конь, слон, ладья, ферзь, король.
Родительный: пешки, коня, слона, ладьи, ферзя, короля. Творительный: пешкой, конём, слоном, ладьёй, ферзём, королём.

Карточка угрозы:
- вилка: «Вилка: {шах королю на e8 и }удар по {ладье a8}. {Пешка c7} не защищена.»
- зевок: «{Ладья d1} не защищена — соперник забирает её ходом {Bxd1}.»
- шах: «Тебе шах от {коня f6}. Сначала защити короля.»
- мат: «Соперник грозит матом: {Qh7#}.»
- материал: «Соперник выигрывает материал: {коротко по линии}.»

Причины в «Твоих отметках»:
- нашёл: «{Конь} бьёт её{ с шахом}.» / «Висит: защиты нет.»
- пропустил: «Попадает под вилку после {Nxc7+}.» / «Висит: защиты нет.» / «Атакована {пешкой}, а стоит дороже.»
- лишняя: «{Ферзь d3} бьёт {f3}, но {слон} защищён {ферзём f6}.» / «Её никто не атакует.»

Итог линии (`outcomeText`): «ты теряешь {ладью}», «ты теряешь {ферзя}», «мат в {N} ходов», «соперник выигрывает {2.5} пешки».
