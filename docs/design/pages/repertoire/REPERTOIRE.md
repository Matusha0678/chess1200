# «Дебюты в партиях» — сайт сам находит, где ты отошёл от своих линий

Пользователь учит свои дебюты в тренажёре (`openings` + `opening_lines`). Нужно, чтобы анализ его партий замечал:
- **отклонение** — в позиции из его линий он сыграл не тот ход, что записан у него («сыграл 5. Nf5, а в твоей линии 5. Nxc6»);
- **дыру** — соперник сыграл ход, которого нет в его линиях («4...Qh4 — нет в твоих линиях»), и подсказывал, что тут обычно играют;
- **в каких дебютах** это случается чаще всего.

Теория вообще не важна — сравниваем только с ходами, которые записаны у пользователя.

Картинки (номера в тексте = номера на картинках):
- `target-deviation-numbered.png` — выбрано отклонение, элементы 1–12;
- `target-hole-numbered.png` — выбрана дыра, элементы 13–15;
- `target-deviation.png`, `target-hole.png` — то же без номеров.

Макет: `docs/design/mockups/repertoire.html` (`#hole`). Эталон логики с тестами: `docs/design/pages/repertoire/repertoire-ref.cjs` — запусти `node docs/design/pages/repertoire/repertoire-ref.cjs`, должно быть `10/10`. Ветка `feat/repertoire`. SQL сам не запускай.

## 0. Общее правило для всех досок сайта

**Значок хода (!!, ??, ?, ✓…) ставим только там, где этот ход уже сыгран на доске.** На позиции «до хода» — только стрелки: красная — сыгранный ход, зелёная пунктирная — нужный. Иначе значок оказывается на чужой фигуре или на пустой клетке (так было в «Жертвах»: «!!» на чёрной пешке).

Это касается и «Играть» (`PLAY.md`, п. 12 и 20 — в этом архиве уже исправлены, и картинка `play/target-over.png` тоже). Если «Играть» уже сделана — убери значок с доски в наведении на «Тренера» и в разборе ошибок.

## 2. Как проверяется партия
Логика — в `repertoire-ref.cjs` (`posKey`, `buildIndex`, `checkGame`). Перенеси её в `src/lib/repertoire.ts` один в один.

- **Индекс репертуара** для цвета C: из всех линий дебютов с `color` = C (`white` / `black`) или `both`. Для каждого хода линии берём позицию **до** хода (`posKey`: расстановка + чей ход + рокировки, без взятия на проходе и счётчиков). Ходы стороны C → `mine`, ходы соперника → `theirs`. В одной позиции может быть несколько ходов (из разных линий) — любой из них «по линии».
- **Сравнение по позициям, а не по номерам ходов**, поэтому перестановка ходов не считается ошибкой. Если ход не из линий, но за 4 полухода партия возвращается в позицию из индекса — это перестановка, идём дальше.
- **Партия** (мой цвет — `games.color`): идём по ходам из `games.pgn` до 30-го полухода.
  - позиции ещё нет в индексе — ищем дальше; позиция была в линиях, а теперь её нет — линия закончилась: `in_line`;
  - мой ход, позиция есть в `mine`, ход не из линий → `deviation`; если это мой первый ход в партии → `other` («другой дебют», не ошибка);
  - ход соперника, позиция есть в `theirs`, ход не из линий → `hole`; если это первый ход соперника → `hole` с `first = true` («нет линий против 1. d4»);
  - в линии так и не вошли → `none`.
- Партии с заголовком `[FEN "…"]` (не с начальной позиции) → `none`.

Статусы и примеры — тесты в конце `repertoire-ref.cjs`.

## 3. Цена отклонения
Для `deviation` берём строку `game_analysis` этого хода (`game_id`, `move_number`, `color`) — поля `classification` и `loss` (потеря шансов, 0–1). Подпись:
- `loss ≥ 0.20` — «зевок», `≥ 0.10` — «ошибка», `≥ 0.05` — «неточность» (+ «(−N%)», N = `round(loss × 100)`);
- меньше — «ход нормальный» (ход не из твоей линии, но не плохой);
- партия не проанализирована — подписи нет.

Если в группе несколько партий — берём самый большой `loss`.

## 4. Таблица `game_openings` — `supabase/30-game-openings.sql`

```sql
-- safe to re-run, run after 25-move-classes.sql
CREATE TABLE IF NOT EXISTS game_openings (
  game_id      uuid PRIMARY KEY REFERENCES games(id) ON DELETE CASCADE,
  status       text NOT NULL CHECK (status IN ('in_line','deviation','other','hole','none')),
  ply          integer,              -- 0-based полуход события
  move_number  integer,
  color        text CHECK (color IN ('w','b')),
  fen_before   text,                 -- позиция до хода-события
  played       text,                 -- SAN
  played_uci   text,
  prev_uci     text,                 -- предыдущий ход (для подсветки последнего хода)
  expected     text[],               -- SAN ходов из линий
  expected_uci text[],
  opening_id   uuid REFERENCES openings(id) ON DELETE SET NULL,
  line_ids     uuid[],
  book_plies   integer NOT NULL DEFAULT 0,
  first        boolean NOT NULL DEFAULT false,
  cls          text,                 -- classification хода-отклонения
  loss         numeric,              -- его loss
  rep_hash     text NOT NULL,
  checked_at   timestamptz DEFAULT now()
);
ALTER TABLE game_openings ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "allow all" ON game_openings;
CREATE POLICY "allow all" ON game_openings FOR ALL USING (true) WITH CHECK (true);
CREATE INDEX IF NOT EXISTS game_openings_status_idx ON game_openings (status);
```
Добавь файл в `supabase/RUN-ORDER.md`.

**Когда проверять.** При открытии `/repertoire` и `/games`:
1. Загрузить `openings` и `opening_lines`, собрать индексы для белых и чёрных, посчитать `rep_hash` — FNV-1a от строки: линии по `id`, каждая `{color}|{SAN через пробел}`, через `\n`.
2. Загрузить `games` (`id, pgn, color, result, played_at, opp_name`) и `game_openings (game_id, rep_hash)`.
3. Проверить партии без строки или с другим `rep_hash` (дебюты изменились — проверяем всё заново). Пачками по 50, между пачками отдавать управление странице (`setTimeout(0)`); в левой колонке — «Проверяю партии: 120 из 480» и полоса.
4. Для `deviation` дочитать `game_analysis` одним запросом (`.in('game_id', ids)`), записать `cls` и `loss`.
5. `upsert` пачками по 100. Любая ошибка Supabase — красная строка 13px «Ошибка базы: {message}. Выполни SQL 30 (supabase/RUN-ORDER.md)», партию не помечать.

## 5. Что играют в позиции — `src/app/api/lichess/explorer/route.ts`
Lichess Opening Explorer теперь требует токен, поэтому запрос идёт через наш сервер, токен — в переменной `LICHESS_TOKEN` (`.env.local` и Vercel). В коде токена нет, `.env.local` не читай.

- `GET /api/lichess/explorer?fen=…`. Нет `LICHESS_TOKEN` → `503 {"error":"no_token"}`.
- Запрос: `https://explorer.lichess.org/lichess?variant=standard&speeds=blitz,rapid,classical&ratings=1200,1400,1600,1800&moves=6&topGames=0&recentGames=0&fen=…`, заголовок `Authorization: Bearer ${LICHESS_TOKEN}`, кэш `next: { revalidate: 86400 }`.
- Ответ сайту: `{ total, moves: [{ san, uci, share, score }] }` — до 5 ходов; `share` = партии хода / все партии; `score` = очки стороны, которая ходит: (победы + ничьи/2) / партии хода.
- `429` → `429 {"error":"rate_limited"}`, другие ошибки → `502`. На странице держать кэш по `fen`, одновременно — один запрос.
- Нет токена → вместо списка ходов строка 13px `--muted`: «Добавь LICHESS_TOKEN, чтобы видеть, что здесь играют».

## 7. Действия
- **«Повторить линию»**: для линии из `line_ids`, в которой есть ход из линии в этой позиции, поставить `line_progress.next_review = now()` (`upsert` по `line_id`; нет строки — создать), потом перейти на `/openings/{opening_id}/practice?line={line_id}` (страница уже понимает `?line=`).
- **«В тренажёр ошибок»**: `mistake_cards` — `game_id` последней партии группы, `fen_before`, `my_move` = сыгранный ход (SAN), `best_move` = ход из линии (UCI), `eval_before` и `eval_loss` из `game_analysis` (нет — `eval_loss = 1`), `phase = 'opening'`, `tag = 'deviation'` (тег уже разрешён в `09-deviation.sql`). Карточка с тем же `fen_before` и `tag = 'deviation'` уже есть → кнопка неактивна: «Уже в тренажёре».
- **«Добавить … в дебют»**: новая строка `opening_lines` (как «Добавить вариации» в редакторе дебюта): `opening_id` из группы, `line_index` = максимум + 1, `moves` = ходы партии от начала до хода соперника включительно + выбранный ответ, в формате `ChessMove` (`san, from, to, fen, color`). Потом `openings.total_lines + 1`, тост «Добавлено — линия появится в тренажёре дебютов», и партии проверяются заново (у репертуара новый `rep_hash`).

## 8. Страница партии `/games/[id]` — строка «Дебют»
Под заголовком партии — одна строка `data-ui="rep-line"` 14px с иконкой `book-check` / `book-x`:
- `in_line`: «{дебют} — по твоей линии {N} ходов» (зелёная иконка);
- `deviation`: «{дебют} — отошёл от линии на {N}-м ходу: {ход} вместо {ход из линии}» + ссылка «Разобрать →» (`/repertoire?game={id}` — открывает страницу с выбранной группой этой партии);
- `hole`: «{дебют} — соперник ушёл из линии на {N}-м ходу ({ход})» + «Что отвечать →»;
- `other` / `none`: «Дебют не из твоих» серым.

Нет строки в `game_openings` — проверить эту партию на месте (та же функция) и записать.
