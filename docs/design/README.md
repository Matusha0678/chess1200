# docs/design — дизайн страниц-тренажёров

Начни с **DESIGN-SPEC.md** и делай всё по разделу 13 «Порядок работы».

- Картинки `*.png` — как должны выглядеть страницы (окно 1920×950).
- `mockups/*.html` — те же макеты в HTML: точные размеры, цвета, отступы.
- `check-design.mjs` — автопроверка страниц (DESIGN-SPEC.md, раздел 14).

Папку `docs/mockups/` (если осталась от прошлого раза) можно удалить — всё есть здесь.
