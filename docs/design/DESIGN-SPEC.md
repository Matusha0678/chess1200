## 1. Цель и границы

- Все страницы с доской выглядят как один продукт: мягкий тёмный стиль, как chess.com.
- Доска большая, на весь экран по высоте. Мало пустого места. Всё ровно, «линия в линию».
- **Только компьютер.** Основное окно — 1920×950 (так выглядит браузер пользователя). Минимальное — 1440×800. Телефоны и планшеты **не поддерживаем** и на них время не тратим.
- В `CLAUDE.md` замени правило «На ширине 390px всё помещается» на: «Только компьютер: проверка на окне 1920×950 и 1440×800».
- Тема «Мягкий» (soft-dark) — основная. Темы «Мягкий светлый» и «Газетный» должны продолжать работать: всё только через CSS-переменные.

## 4. Сетка страницы-тренажёра

### 4.1. Схема (окно 1920×950)

```
┌──────────────────────────── верхняя шапка 56px (как сейчас) ─────────────────────────────┐
├ меню 240px ┬─20─┬ Сессия 280 ┬─20─┬ 24 ┬8┬ доска S ┬─20─┬ Панель задания (остаток) ┬─20─┤
│            │    │  карточка  │    │    │ │ полоска игрока 32px          │                          │
│            │    │            │    │ ев │ │ ─ 8px ─                       │    карточка             │
│            │    │            │    │ ал │ │ ДОСКА S×S                     │                          │
│            │    │            │    │ ба │ │ ─ 8px ─                       │                          │
│            │    │            │    │ р  │ │ полоска игрока 32px          │                          │
└────────────┴────┴────────────┴────┴────┴─┴──────────────┴────┴──────────────────────────┴────┘
                     сверху и снизу отступ 20px; три колонки одной высоты
```

### 4.2. Числа

- Высота рабочей области: `H − 56` (шапка). Внутри отступы 20px со всех сторон. Высота карточек: `cardH = H − 56 − 40`.
- Колонка доски: ширина `24 (полоса оценки) + 8 + S`, высота `32 + 8 + S + 8 + 32`. Полоска игрока начинается от левого края доски (у неё `padding-left: 32px`, чтобы текст стоял над доской, а не над полосой оценки).
- `S` — размер доски, **целое число, кратное 8** (каждая клетка — целое число пикселей):
  1. `S_h = cardH − 2·32 − 2·8`
  2. `S = min(S_h, 900)`, округлить вниз до кратного 8.
  3. Ширина рабочей области `W_main = W − ширина меню (240 или 64) − 40`.
  4. Левая колонка «Сессия» (280px) показывается, только если помещается: `280 + 20 + (32 + S) + 20 + 420 ≤ W_main`.
  5. Правая панель: `W_right = W_main − (левая ? 300 : 0) − (32 + S) − 20`. Если `W_right < 420` — уменьшай `S` (шаг 8), пока не станет 420. Если `W_right > 600` — ограничь 600, а лишнее раздели поровну по краям (вся группа по центру).
  6. Если по вертикали остался запас (меньше 8px из-за округления) — колонку доски центрируй по вертикали.
- Готовые значения:

| Окно | S | Клетка | Левая колонка | Правая панель |
|---|---|---|---|---|
| 1920×950 | 768 | 96 | да | 520 |
| 1440×800 | 624 | 78 | нет | 484 |
| 1600×900 | 720 | 90 | нет | 548 |
| 2560×1400 | 896 | 112 | да | 600 + центр |

На картинках-макетах доска 774px (не кратно 8). В коде будет 768 — это нормально, разница 6px.

- Когда левой колонки нет: в шапке правой панели справа появляется кнопка «Сессия» (иконка списка), которая открывает выпадающую панель с тем же содержимым (поверх, ширина 320px). Счёт сессии (верно / ошибок / серия) тогда показывай одной строкой под полосой прогресса.
- Страница не прокручивается. Прокручиваются только список в левой колонке и середина правой панели, если не влезают.
- Пересчёт при изменении размера окна (`resize`). Сделай хук `useTrainerGeometry()` → `{ S, showLeft, rightWidth }`.

### 4.3. Левое меню сайта

Внизу меню — кнопка «Свернуть меню» (иконка `panel-left-close`): 240px ↔ 64px (только иконки, подсказка в `title`). Состояние в `localStorage` (`chess1200-sidebar-collapsed`, читать в try/catch). Сетка тренажёра учитывает текущую ширину меню.

## 5. Доска: компонент `Board`

Файл: `src/components/board/Board.tsx`. **Единственный** файл, который импортирует `react-chessboard`. Добавь в ESLint правило `no-restricted-imports` для `react-chessboard` с исключением для этого файла.

### 5.1. Интерфейс

```ts
import type { Square } from 'chess.js';

export type BadgeKind =
  | 'brilliant' | 'great' | 'best' | 'excellent' | 'good' | 'book'
  | 'inaccuracy' | 'mistake' | 'miss' | 'blunder'
  | 'found' | 'missed' | 'wrong';           // для «Проверки угроз»

export interface BoardArrow {
  from: Square; to: Square;
  color: string;                 // см. 5.5
  style?: 'solid' | 'dashed';    // по умолчанию solid
  opacity?: number;              // по умолчанию 0.85
  label?: string;                // число в кружке на стрелке (план: «2», «3»)
}

export interface BoardProps {
  fen: string;                              // всегда полный FEN (не 'start')
  orientation: 'white' | 'black';
  size: number;                             // S из useTrainerGeometry, кратно 8
  interactive?: boolean;                    // можно ходить (перетаскивание и клики)
  movableColor?: 'w' | 'b';                 // чьими фигурами можно ходить; по умолчанию — чей ход в FEN
  onMove?: (m: { from: Square; to: Square; promotion?: 'q'|'r'|'b'|'n' }) => boolean | Promise<boolean>;
  onSquareClick?: (sq: Square) => void;     // режим «отметь клетки» (угрозы); тогда interactive=false
  lastMove?: { from: Square; to: Square } | null;
  tints?: Partial<Record<Square, string>>;  // заливка клетки rgba(...)
  rings?: Partial<Record<Square, string>>;  // рамка 4px внутрь клетки
  badges?: Partial<Record<Square, BadgeKind>>;
  arrows?: BoardArrow[];
  checkSquare?: Square | null;              // красное свечение под королём
  dimmed?: boolean;                         // пустое состояние: доска приглушена
}
```

### 5.2. Главное правило (из-за него были маленькие фигуры)

В react-chessboard 5 клетка — `display:flex` по центру. Если `squareRenderer` вернул **любой** элемент (даже `<>{children}</>`), библиотека **не рисует** свою обёртку клетки (`div` 100%×100% со `squareStyles`). Фигура остаётся без размера и сжимается, а подсветка клетки пропадает.

Поэтому:
- **`squareRenderer` не использовать совсем.**
- Заливку, рамку, свечение шаха, точки ходов — передавай через `squareStyles` (свойства `background` и `boxShadow`). Они попадают в обёртку клетки под фигурой, фигура остаётся 100% клетки.
- Несколько эффектов на одной клетке — складывай: несколько `background` через запятую (сверху вниз), `boxShadow` — тоже через запятую.
- Значки и стрелки — в отдельном слое поверх доски (раздел 5.4).

### 5.3. Как выглядит доска

- Размер — ровно `size`×`size` пикселей: `boardStyle: { width: S, height: S, borderRadius: 6 }`. Никаких процентов, `aspect-ratio` и `overflow:hidden` у родителей, которые меньше доски. Каждая клетка ровно `S/8`.
- Цвета клеток — только из `useBoardTheme()` (`boardTheme.light`, `boardTheme.dark`). Никаких своих цветов.
- Фигуры — `customPieces` из темы; если стиль «Стандарт» — фигуры библиотеки. Фигура занимает всю клетку (рисунок внутри ~90%).
- Координаты: цифры в левом верхнем углу клеток левого столбца, буквы в правом нижнем углу клеток нижнего ряда (так делает библиотека). Стиль: 13px, 600. Цвет — цвет **противоположной** клетки: на светлой клетке `boardTheme.dark`, на тёмной `boardTheme.light` (`lightSquareNotationStyle`, `darkSquareNotationStyle`).
- Анимация хода: `animationMs` из темы; если `prefers-reduced-motion` — 0.
- Ключ перемонтирования: только `${boardThemeId}-${pieceStyleId}-${orientation}`. **Не** меняй ключ на каждый ход — иначе нет анимации.
- `dimmed`: поверх доски слой `rgba(38,37,34,.55)` со скруглением 6px, ходить нельзя.

### 5.5. Слой поверх доски (значки и стрелки)

- Обёртка `position:relative; width:S; height:S`. Внутри: доска, затем слой `position:absolute; inset:0; pointer-events:none`. Слой **не обрезается** (значки на краю доски вылезают наружу — так и надо).
- Координаты центра клетки (размер клетки `q = S/8`):
  - белые снизу: `x = (file + .5)·q`, `y = (8 − rank + .5)·q`
  - чёрные снизу: `x = (7 − file + .5)·q`, `y = (rank − 1 + .5)·q`
  (`file`: a=0 … h=7, `rank`: 1…8)
- **Сплошная стрелка** (SVG-многоугольник): от центра «откуда» + 18px до центра «куда» − 14px; полуширина стержня 9px; полуширина наконечника 22px; длина наконечника 34px. Пересчитывай под `q` пропорционально (эти числа — для q=96).
- **Пунктирная стрелка**: линия толщиной 6px (для q=96), `stroke-dasharray: 12 9`, скруглённые концы; треугольный наконечник 20×24.
- **Номер на стрелке**: кружок радиус 15px, цвет `#3A78C2`, белая цифра 16px/800. Ставь на 30–45% длины стрелки, чтобы не закрывать фигуры.
- Цвета стрелок: лучший ход / моя стрелка ответа — `#81B64C` (или оранжевая `#F0A43A` для «удар по цели»); угроза соперника — `#E0574A`; цели вилки — пунктир `#F0A43A`; план после жертвы — `#4A90E2` с прозрачностью .55–.7; предложение жертвы — пунктир `#F0A43A`.
- **Значок** (`ClassIcon`): круг диаметром `0.375·q` (36px при q=96), в правом верхнем углу клетки: `left = x_клетки + q − 0.25·q`, `top = y_клетки − 0.125·q` (центр значка чуть внутри угла). Тень `drop-shadow(0 2px 3px rgba(0,0,0,.45))`.

Сейчас `src/components/ClassIcon.tsx` использует PNG-иконки chess.com из `public/move-classes/`. Это их собственность, а сайт публичный. **Замени на свои SVG** и удали PNG:
круг цвета класса (`r=11.5` в `viewBox 0 0 24 24`), внутри белый знак из таблицы 3.2. Текстовые знаки — Inter 800, белые; звезда — пятиконечная; галочка, крест — линии толщиной 2.6, скруглённые; палец вверх и книга — иконки `thumbs-up` и `book-open` из lucide-react (белые, 13px внутри круга).

### 5.7. Ходы

- Перетаскивание (как сейчас) **и** клики: клик по своей фигуре → выделение + точки допустимых ходов → клик по клетке → `onMove`. Клик по другой своей фигуре — переключает выбор. Клик мимо или `Esc` — снимает выбор.
- Если `onMove` вернул `false` — фигура возвращается.

## 10. Движок

Используй `useStockfish()`:

### 14.1. Скрипт

`node docs/design/check-design.mjs [адрес] [страницы…]` — по умолчанию `http://localhost:3001` и все тренажёры.
