# Макеты страниц-тренажёров (эталон)

Это эталон внешнего вида. Сайт должен выглядеть как эти картинки.

| Страница | Картинка | HTML |
|---|---|---|
| Ошибки | trainer-layout.png | mistakes.html |
| Проверка угроз — вопрос | threats-1-question.png | threats.html |
| Проверка угроз — после проверки | threats-2-answer.png | threats.html#a |
| Жертвы — вопрос | sac-1-question.png | sac.html |
| Жертвы — ответ | sac-2-answer.png | sac.html#a |

Правила:
- Размеры, цвета, скругления, отступы и размеры шрифтов бери из CSS в HTML-файлах, а не на глаз.
- Окно для сравнения: 1920×950. Колонки: левая 280px, доска 774px (+ полоса оценки 24px и зазор 8px), правая панель — остаток. Отступы 20px. Полоски игроков 32px над и под доской.
- Чтобы открыть HTML: Playwright, file://…/docs/mockups/threats.html (для состояния «ответ» добавь #a).
- После правки делай скриншот своей страницы 1920×950 и сравнивай с картинкой рядом. Отличия по размерам больше 10px — исправляй.
- Позиции и тексты на макетах — пример. Логику и данные бери из кода.
