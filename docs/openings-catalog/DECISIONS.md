# /openings catalog — решения

- Hero-блок на фоне `--surface` с верхней золотой линией 2px (`color-mix(in srgb, var(--accent) 70%, var(--hairline))`) — как у coach-cards.
- Правое превью в hero (доска 232px) берётся из топ-дебюта по due (первый в отсортированном списке с due>0). Если due нет и в состоянии «Всё повторено» — доска из первого дебюта с новыми линиями.
- Очистка названия от префикса «📚 Авторский • …» — regex `/^\s*(📚\s*)?авторск\S*\s*[•·—-]\s*/i`; результат показывается в карточке, но в базе не трогаем. Чип «Авторский» ставится если исходное имя match'ило этот regex (= `isAuthored(op)`).
- Карточка дебюта: убраны hover-overlay, круглая галочка mastered, карточка «+ Новый дебют» в конце сетки, бейдж «Новых · N». Остались бейджи «ПОВТОРИТЬ · N» и «ОСВОЕНО».
- Оба фильтра (color, show) + вкладки категорий + поиск — в одну строку сверху сетки (на узком экране wrap).
- Cover-доска hero: при `op.cardFen` показываем через `MiniBoard`; last-move берём из первых ходов (последний SAN).
- `op-hero` / `op-filters` / `op-search` / `op-categories` / `op-review-all` — ровно как в ТЗ. `eg-left` больше не существует.
- Loading skeleton — 8 пустых карточек-рамок той же формы, без центрального «Загрузка…».
