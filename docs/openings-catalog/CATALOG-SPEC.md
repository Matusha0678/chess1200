# Каталог дебютов (/openings) — новый вид. ТЗ для Claude Code

Версия 1 · 21 ноября 2026

Страница `/openings` переходит на тот же стиль, что и `/tal`: Executive, заголовки с засечками, тонкие линии, золото — только для главного. Логика страницы не меняется, меняется вид и расположение блоков.

---

## 0. Как работать

1. Прочитай `CLAUDE.md`, `AGENTS.md` и этот файл целиком.
2. Эталон вида — `docs/openings-catalog/catalog-reference.html`. Открой в Playwright (`file://<проект>/docs/openings-catalog/catalog-reference.html`), окна 1920×950 и 1440×800. Цвета, размеры, отступы и шрифты бери оттуда. Названия и цифры — пример (10 дебютов из 23).
3. Шапка сайта и левое меню в эталоне — только для вида, они уже есть в `AppShell`. Доски в эталоне нарисованы картинками; на сайте — `MiniBoard` с темой доски из настроек.
4. Меняется только `src/app/openings/page.tsx` (и стили). Другие страницы не трогай.
5. Ветка `feat/openings-catalog`, маленькие коммиты. В main не мержи и не пушь, пока я не проверю.
6. Если что-то неясно — выбери вариант ближе к эталону и запиши решение одной строкой в `docs/openings-catalog/DECISIONS.md`. Вопросов не задавай.
7. Только CSS-переменные, никаких hex. Таблица соответствия цветов — `docs/coach/COACH-SPEC.md`, раздел 2. Токен `--text-2` уже есть в `globals.css`.

## 1. Что меняется

- **Левой панели больше нет.** Её содержимое переезжает:
  - «Повторить всё · N», «Дебют Рандом», подсказка про Stockfish и 4 счётчика → блок «На повтор сегодня» под заголовком (раздел 3);
  - фильтры «Цвет» и «Показать» → в одну строку с категориями (раздел 4);
  - «Добавить дебют» → кнопка справа от поиска в шапке (раздел 2).
- **Сетка карточек — на всю ширину.** Страница прокручивается целиком, как `/tal`. Внутренней прокрутки у сетки нет (сейчас там `height: calc(100vh - …)` и `overflow: hidden` — убрать).
- **Карточки — новый вид** (раздел 5).
- **Правильные окончания слов** (раздел 6). Сейчас на сайте «23 дебютов», «61 линий», «64 линий».

Обёртка — обычный `div.page` (max-width 1400, padding 32/32/56, gap 24px).

## 3. Блок «На повтор сегодня» (`data-ui="op-hero"`)

Карточка: фон `--surface`, рамка 1px `--hairline`, сверху золотая линия 2px (`color-mix(in srgb, var(--accent) 70%, var(--hairline))`).

**Верх** (padding 32px 36px, flex-wrap, gap 32px):
- Слева:
  - надзаголовок «На повтор сегодня»;
  - крупно: число (засечки, курсив, 76px, `--accent`) + «линий ждут повторения» (засечки, 32px). Глагол по числу: «1 линия ждёт», «3 линии ждут», «18 линий ждут»;
  - текст 15px `--text-2`, до 520px: «Все — из Scotch Gambit. Займёт около 18 минут. Повторяй по сроку — так линии остаются в памяти.» Если линии из нескольких дебютов — «Больше всего — в <дебют> (N).». Время — 1 линия ≈ 1 минута, как сейчас;
  - кнопки: золотая «Повторить всё · 18 →» (`data-ui="op-review-all"`, → `/openings/review`, в демо `?demo=1`) и контур «Дебют Рандом» (→ `/openings/random`). Высота 48px, caps 13px;
  - подпись 13px `--muted`: «Дебют Рандом — Stockfish играет против твоих линий, ты отвечаешь.»
- Справа: доска 232px дебюта, где больше всего линий к повтору (`MiniBoard`, его `cardFen`, ориентация по цвету). Рамка 1px `--hairline-2`, внутри отступ 6px, фон `--bg`. Под доской: название (засечки, курсив, 16px) и последний ход (моноширинный 13px). На узком экране доска скрывается.

**Низ**: 4 ячейки через линии 1px: «Повторить» (число золотом), «Изучаю», «Освоено» (с подписью «из 1000»), «Новых». Подпись — caps 13px `--muted`, число — засечки, курсив, 34px.

**Состояния:**
- Нет линий к повтору → заголовок «Всё повторено», текст «Новых линий: 982. Начни с <первый дебют с новыми линиями>.», золотая кнопка «Учить новые →» в этот дебют, доска — этого дебюта. Кнопку `op-review-all` оставь неактивной с текстом «Всё повторено» — чтобы проверка её находила.
- Нет ни одного дебюта → вместо блока пустое состояние: «Добавь первый дебют», «Вставь PGN с вариантами — линии появятся сами», кнопка «Добавить дебют».

- Под всей строкой — линия 1px `--hairline`. На узком экране строка переносится.
- Логика вкладок, фильтров и поиска — как сейчас (`op-filters` в localStorage, счётчики с учётом фильтров, `?q=`, клавиша `/`).

## 5. Карточка дебюта (`data-ui="eg-card"`, `data-status` как сейчас)

Сетка: `grid-template-columns: repeat(auto-fill, minmax(230px, 1fr)); gap: 16px`. На 1920 — 5 колонок, на 1440 — 4. Доска всегда не меньше 230px (так требует `check-design.mjs`).

- Карточка: фон `--surface`, рамка 1px `--hairline`, острые углы. При наведении рамка золотится (accent 50%), а действие внизу становится золотым. Подъёма и теней нет. Вся карточка — ссылка на `/openings/[id]` (в демо — `/openings/demo`).
- Доска (`data-ui="eg-board"`): квадрат на всю ширину карточки. Табличка слева сверху (10px от краёв) — только в двух случаях:
  - есть линии к повтору → золотая «ПОВТОРИТЬ · 18»: фон `--accent`, текст `--accent-contrast`, caps 13px, высота 26px;
  - всё освоено → контур «ОСВОЕНО»: рамка accent 55%, фон `color-mix(in srgb, var(--bg) 78%, transparent)`.

  Таблички «Новых · N» больше нет. Круглой галочки и затемнения с кругом «play» при наведении — тоже нет.
- Под доской (padding 14px 16px 16px, линия сверху), сверху вниз:
  1. номер по порядку «01» (засечки, курсив, 20px, `--accent`); если дебют авторский — рядом метка «АВТОРСКИЙ» (caps 13px, `--text-2`);
  2. название (`data-ui="eg-card-title"`): засечки 18px, line-height 1.25, максимум 2 строки. Высота всегда как у 2 строк (45px) — чтобы строки в соседних карточках стояли ровно;
  3. «♔ Белыми · 76 линий» (♚ — чёрными, ♗ — за оба), 13px `--text-2`;
  4. первые ходы — моноширинный 13px `--muted`, одна строка, в конце «…»;
  5. полоса 2px: освоено (`--accent`) + изучаю (`color-mix(in srgb, var(--accent) 60%, var(--surface))`), фон `--track`;
  6. строка: слева «освоено 0 из 76» (13px `--muted`), справа действие (13px, 600):
     - есть к повтору → «Повторить 18 →» (`--accent`);
     - есть новые → «Учить →»;
     - всё освоено → «Экзамен →»;
     - иначе → «Продолжить →».
- **Название.** Из «📚 Авторский • Королевский гамбит» показывай «Королевский гамбит» и метку «Авторский». Убирай значок и приставку регулярным выражением вида `/^\s*(📚\s*)?авторск\S*\s*[•·—-]\s*/i`. В базе названия не меняй. Категория «Авторские» работает как раньше — по полному названию.
- Карточку «＋ Новый дебют» в конце сетки убери — кнопка «Добавить дебют» теперь в шапке.
