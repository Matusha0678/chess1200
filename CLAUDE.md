# Chess 1200 — правила для Claude Code

## 1. Перед кодом

Прочитай AGENTS.md (если есть) и нужный раздел документации в `node_modules/next/dist/docs/`.
Это не стандартный Next.js — сверяйся с локальной документацией, а не с обучающими данными.

## 2. Язык интерфейса

Русский. Тексты простые и короткие.

## 3. Дизайн — правила по темам

Сайт поддерживает две семьи тем: **«Газетный»** и **«Мягкий»** (тёмный/светлый вариант).  
Переключатель: `siteThemeId` в localStorage (`chess1200-board-settings`).  
Все темы работают через CSS-переменные (`--bg`, `--surface`, `--ivory`, `--muted`, `--hairline`, `--accent`, `--radius-card`, `--radius-btn`, `--shadow-card`).

### Тема «Газетный» (ID-ы: `dark`, `midnight`, `indigo`, … и другие тёмные + `light`)

- Острые углы, `--radius-card: 0px`, тонкие линии (`border: 1px solid var(--hairline)`), без теней.
- Газетный стиль: крупные плотные заголовки, нумерованные списки (01, 02), много контраста.
- Компактно и ровно, всё выровнено «линия в линию».
- **Вместо кружков как индикаторов** — цифры (3/5) или тонкие полосы.
- Минимальный размер текста — 13px.
- Не делать стиль мобильного приложения.

### Тема «Мягкий» (ID-ы: `soft-dark`, `soft-light`)

- Скругления 10–14 px: `--radius-card: 12px`, `--radius-btn: 10px`.
- Тени вместо жёстких рамок: `--shadow-card: 0 2px 8px rgba(0,0,0,…)`.
- Акцент — зелёный `#81B64C` (`--accent`): главные кнопки, прогресс.
- Шрифт без засечек, жирные заголовки. Текст не мельче 14px.
- Отступы кратны 8px. Много воздуха, но компактно.
- Прогресс: скруглённые полосы и текст «2/5». Анимации 200–300 мс, учитывать prefers-reduced-motion.
- Навигация: TopNav остаётся, но цвета и скругления соответствуют теме.

### Общие правила (все темы)

- Токены из `src/app/globals.css`: `--bg`, `--surface`, `--ivory`, `--muted`, `--hairline`.
- Только тёмная тема по умолчанию. Светлый вариант добавлен как `light` и `soft-light`.

Если фиче нужны новые таблицы:
- Добавь файл `supabase/NN-имя.sql` (NN — порядковый номер).
- SQL безопасен для повторного запуска: `IF NOT EXISTS`, доступ открыт так же, как у остальных таблиц.
- SQL сам не запускай.
- В конце ответа напиши, какие файлы выполнить и в каком порядке.
